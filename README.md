# Wild Quest

Wild Quest is an educational game for kids where players guess the animal based on progressively revealed clues.

## Features
-   Fun and interactive gameplay
-   Educational clues about animals
-   Photorealistic images of animals in their natural habitats
-   Score tracking and levels

## Running Locally

1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm run dev`.
4.  Open `http://localhost:5173`.

## Deployment

This project is deployed on GitHub Pages with a custom domain: [wildquest.net](https://wildquest.net).
